# Contributing

Create a short-lived branch from current `main`. Keep changes focused and run the checks in [Local setup](docs/SETUP.md) before opening a pull request. Include the behavior changed, verification results, and any effect on schema, policy, approvals, or runtime configuration.

Use synthetic fixtures. Keep credentials, local SQLite databases, environment files, and generated dependencies out of commits. For an unresolved finding, follow [Security](SECURITY.md).
